# 跨境增长 Agent 工作流设计

## 目标

在现有电商多 Agent 平台中增加“市场研究 → Listing → 合规 → 审批 → 模拟发布”闭环，展示从分析到受控执行的能力。

## 约束

- 数据与发布均为模拟，不声称接入真实 Amazon、Temu 或 Walmart。
- 发布必须绑定已批准的 `listing_publish` 建议。
- 工作流完整快照写入建议证据，刷新和重启后可恢复。
- 合规失败时不创建可发布内容。

## Agent

- Market Research Agent：结合商品经营、竞品价格和评论主题生成市场机会。
- Listing Agent：输出标题、五点描述、关键词和目标平台。
- Compliance Agent：检查绝对化用语、受限词和标题长度。
- Workflow Agent：编排状态、创建审批建议并生成模拟发布回执。

## 验收

- API 可创建并读取持久化工作流。
- 未审批发布返回 409。
- 审批后发布返回稳定的沙箱回执。
- 页面展示 DAG、研究结论、Listing、合规检查与审批状态。
