# 3 分钟演示脚本

1. 注册并登录，说明无 PostgreSQL 时开发环境使用本地账号降级。
2. 打开运营驾驶舱，展示 90 天趋势、GMV 归因、转化漏斗和 7 天模拟预测。
3. 打开运营 Agent，输入“昨天 GMV 为什么下降？”，展示执行模式、Agent 执行轨迹、数据证据和建议动作。
4. 继续追问“具体哪些商品有风险？”，展示同一会话的多轮上下文和持久化历史。
5. 打开客户分析，展示 RFM、复购率和模拟 LTV；打开商品分析查看 ABC、周转和竞品价差。
6. 在活动策略切换“新品冷启动”和“清仓库存”，展示不同选品及活动模拟收益。
7. 在建议审批填写意见并通过建议，再打开审批审计查看版本和时间线。
8. 在运行中心查看确定性降级、耗时和工具明细；在 Agent 评测展示 40 条标准问题报告。

结束说明：项目串联了数据建模、分析工具、混合 Agent、会话记忆、可观测性、评测和人工审批。DeepSeek 不可用时仍可完整演示，高风险动作始终由规则与人工审批控制。
