# 简历项目描述：智能电商运营 Agent 平台

## 推荐版本

**智能电商运营 Agent 平台｜个人项目**

技术栈：Python / FastAPI / DeepSeek / SQLAlchemy / Vue 3 / TypeScript / pytest / Playwright

- 设计 DeepSeek 与确定性工具结合的混合电商运营 Agent，使用 Pydantic 结构化计划约束工具白名单和最大执行步数，模型不可用时自动进行确定性降级。
- 基于固定随机种子构建 90 天电商经营数据，覆盖订单、流量、广告、库存、评价、客户、活动和竞品价格，完成 GMV 归因、漏斗、ABC、RFM、复购率、模拟 LTV、活动 ROI 和 GMV 预测。
- 实现多轮会话、Agent 运行轨迹和 SQLite/PostgreSQL 双模式持久化，记录执行模式、工具耗时、Token、降级原因与 P95 延迟。
- 设计建议审批和审批审计机制，通过版本控制、幂等键、审批意见与状态流转限制高风险操作，模拟企业级人机协同。
- 建立 40 条、8 类场景的 Agent 评测集，自动评估意图、工具、参数、证据和风险准确率；确定性基线评测 40/40 通过，平均耗时约 2ms（本地模拟数据，不含模型网络延迟）。
- 使用 pytest、Vue 类型检查和 Playwright 覆盖后端契约、桌面/移动端 Agent、活动选品、审批与运行中心流程。

## 面试边界

- DeepSeek 只负责计划与解释，指标、风险和审批策略由 Python 决定。
- 90 天数据、活动收益和 LTV 均为模拟测算。
- 项目支持 PostgreSQL 生产配置，仅作为生产架构设计展示。
- 运营知识库是辅助模块，不是电商 Agent 的主决策数据源。
